# 16s-rrna-bioinformatics-analysis
🚀 Bioinformatics Project | Comparative Analysis of Bacterial 16S rRNA Genes

I completed a bioinformatics project focused on the comparative analysis of bacterial 16S rRNA gene sequences to understand evolutionary conservation and taxonomic diversity.

Using Python and Biopython, I extracted key biological features such as sequence length and GC content from FASTA sequences obtained from NCBI. I then performed BLASTn analysis to validate species identity and assess sequence similarity.

🔬 Key Highlights:
-Analyzed 16S rRNA sequences from E. coli, Klebsiella, Salmonella, Pseudomonas, and Staphylococcus aureus
-Observed highly conserved gene lengths (~1400–1600 bp), confirming 16S rRNA as a reliable taxonomic marker
-Identified GC content variation reflecting evolutionary and taxonomic differences
-Achieved ≥99% BLAST identity with near-zero E-values, confirming accurate species-level classification
-Visualized comparative patterns using Matplotlib

🛠 Tools Used: Python, Biopython, Pandas, Matplotlib, NCBI BLAST, Google Colab

This project strengthened my understanding of bioinformatics analysis, biological data interpretation, and sequence-based taxonomy.
